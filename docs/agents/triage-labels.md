# Triage Labels

## Label Mapping

Use this five-role vocabulary for local markdown issues and future tracker labels.

| Canonical role | Label |
| --- | --- |
| Maintainer needs to evaluate | `needs-triage` |
| Waiting on reporter or user | `needs-info` |
| Fully specified and ready for an agent | `ready-for-agent` |
| Needs human implementation or judgment | `ready-for-human` |
| Will not be actioned | `wontfix` |

## Local Markdown Usage

When writing local issue files, put labels near the top:

```markdown
Labels: needs-triage, ready-for-agent
```

## Future Tracker Migration

If this project moves to GitHub Issues, create these labels there or update this mapping to match the repo's existing label vocabulary.
