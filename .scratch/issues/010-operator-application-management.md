# Add operator application management slice

Labels: needs-triage
Type: product-slice

## What to build

Promote activity application review from a small embedded admin action into a clear operator workflow for filtering, approving, and auditing member applications.

## Acceptance criteria

- [ ] Operators can list applications by activity and state.
- [ ] Operators can approve an application and see the updated approval state immediately.
- [ ] Cancelled applications remain visible for audit but cannot be approved.
- [ ] Member-facing pages continue to show only the current user's application state.
