# Plan Discord notification publishing

Labels: ready-for-human
Type: product-slice

## What to build

Define the first thin Discord publishing path from website source-of-truth content to a Discord announcement channel without turning Discord into the content store.

## Acceptance criteria

- [ ] Source content type is chosen: notice, activity, or showcase.
- [ ] Publishing target and permission policy are chosen.
- [ ] Webhook or bot execution path is selected.
- [ ] Failure behavior is defined so website publishing does not silently fail.

## Blocked by

- Human choice of Discord channel/publishing policy.
