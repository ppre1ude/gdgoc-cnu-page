# Decide member profile approval fields

Labels: ready-for-human
Type: HITL

## What to build

Decide which guest profile fields are required before an operator can approve a guest into member status, then enforce that decision in the approval workflow.

## Acceptance criteria

- [ ] Required approval fields are explicitly chosen.
- [ ] Guest profile submission validates the required fields.
- [ ] Operator approval UI distinguishes complete and incomplete profiles.
- [ ] The decision is reflected in the PRD or product checklist.

- Human decision on approval policy.
